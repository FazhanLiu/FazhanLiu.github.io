Projects

主なプロジェクト

RAG & Agent

企業製品案内AIエージェント

企業サイト、展示施設、購入前の相談向けにPython・FastAPI・DeepSeekで構築した製品Q&Aアシスタント。PDFの抽出・分割、BGE埋め込み、Chromaへの永続保存、上位5件の検索とCrossEncoderによる再ランキングを経て、ファイル名・ページ番号付きの中国語回答を生成します。意図分類により製品質問、見積もり・デモ予約時の連絡先収集、契約相談の担当者案内を処理。同意を得た連絡先のSQLite保存、文書の自動読み込み、重複排除、文字化け対策、CSVによる意図分類評価にも対応しています。

RoboCup

RoboCup UR5e Object Sorting System

有限状態機械で卓上のYCB物体検出、3D位置・把持推定、障害物回避を伴う経路計画、UR5e制御を連携させ、色別の仕分けを実現するシステムです。私はperception_yoloを担当し、YOLOv26による物体検出、YCB分類、色認識、3D位置推定、スコア付与を実装。GraspNet、MoveIt、実行モジュールへ知覚情報を提供しました。

Graph Neural Network

スケッチ認識

QuickDrawデータセットを用いたGNNベースのスケッチ認識を開発。実現可能性の分析、モデル学習、デモ、最終発表に参加し、成果はICAIC 2024で発表されました。

Computer Vision

物体検出

チームリーダーとしてPythonとYOLOによる物体検出プロジェクトを推進。物体認識、精度評価、最終デモを実施しました。

Robotics Perception

製造業向け協働ロボットの知覚アルゴリズム

産業動作認識のための30クラス動画分類タスクを構築。C3D_Liteを基にC3D_Lite_V2を開発し、注意機構と多層分類ヘッドを導入して性能向上に取り組みました。
